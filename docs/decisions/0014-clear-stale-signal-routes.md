# ADR 0014: Clear stale wires before late electrical repair and rerouting

Date: 2026-10-04. Status: accepted for the fifth physical characterization.
Amends ADR 0013's repair sequence.

The fourth candidate's late repair found four fanout violations and inserted six
buffers. However, global routing skipped previously detailed-routed nets (zero
nets initially routed; only ten after connectivity changed). The next detailed
router rejected obsolete wires with DRT-0206 connectivity errors. Implementation
failed; final extraction, GDS, gate simulation and precheck did not complete.

Before each of the two bounded late repair passes, call OpenDB's `destroyRoutes`
on the current block and write the resulting database. The pinned OpenROAD
implementation explicitly retains supply nets, special routing, special-wire
nets and abutment connections. Cells, connectivity, placement and antenna diodes
remain. Normal signal and clock wires are regenerated by the subsequent global
and detailed routing. The clock tree cells and clock constraints remain unchanged.

Implement this as a separate named plugin step with explicit enable gates. Do
not bypass connectivity checks or reuse a stale guide file. The unchanged final
acceptance criteria still require extracted electrical, antenna, timing, DRC/LVS,
gate simulation and precheck success on the same geometry. This change has local
flow-order validation only until the next physical run is reviewed.

Source reviewed: pinned OpenROAD `dcf36133a369abc8f3c5e5738cd4d82e4903c0e0`,
`src/odb/src/db/dbBlock.cpp`, `dbBlock::destroyRoutes()` and its Tcl binding.
No RTL, PDK, electrical limits, footprint, clock period, pin map, reset or
instruction timing changes.
